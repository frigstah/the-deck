Identity routes  /  The Deck 1.0.0.6

Five ways to put a face on a thing that has never had one.

The Deck ships with no logo and no icon. There is no .ico in the repository, nothing declared in the project file or the installer, and the notification area draws a plain grey circle at runtime because that was the honest placeholder. So this is not a redesign — it is the first mark the product will have.

Every route below is drawn in the app's own palette and set in the app's own faces, then dropped into real surfaces at real sizes: the 78-pixel block at the head of the rail, the deck itself, the mini strip, the taskbar, the tray. Flip On air in the bar above to see each one hold up while a station is live.

It has to work at 16 pixels
That is the tray, and the tray is where this app lives during a show. Anything that needs detail to be recognised has already failed.
It has to carry state
Off air, connecting, on air. The icon is the only thing visible when the window is minimised, so it has to say which.
The mark must stand without the word
And the word must stand without the mark. They meet in the lock-up; they do not depend on each other.
It must speak the window's language
Square corners, one-pixel rules, monospace legending. A soft, rounded, gradient mark would look borrowed from another product.
The honest test

All five, at the sizes that actually decide it.

Drawn at true pixel dimensions — no scaling, no zoom. The 16-pixel column is the tray icon during a live show; the 24 is the taskbar. If a route only convinces in the left-hand column, it is a poster and not an identity.

Where this goes next

Pick one and it becomes eleven files and five edits.

Everything above is vector source, drawn on a 64-unit grid with a separate small-size cut below 20 pixels. Choosing a route turns it into the real package:

  • The icon — a single multi-resolution .ico carrying 16, 20, 24, 32, 40, 48, 64, 128 and 256, each size hinted rather than downsampled, plus PNGs for the readme and the release page.
  • The window — ApplicationIcon in Deck.App.csproj, so the taskbar and Alt-Tab stop showing the default WPF sheet.
  • The tray — TrayPresence.BuildIcon currently fills an ellipse; it would draw the mark instead and keep the three state colours it already has.
  • The title bar — the wordmark in the rail block becomes the lock-up, drawn as geometry rather than as text in Consolas.
  • The installer and the releases — SetupIconFile and the wizard image in installer/Deck.iss, and the readme header.

One caveat worth stating plainly: the wordmarks on this page are set in Segoe UI Variable Display and Consolas, which are the faces the app itself renders in. That is deliberate — but a wordmark that is live text is not a wordmark. Whichever route wins, its lettering gets drawn to outlines and the spacing set by hand, so it is identical on every machine and at every size.
